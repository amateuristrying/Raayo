# Changelog

- Landing page defaults to light mode with a persistent sun/moon switch beside RAAYO.
- Light mode uses a true-white background; sphere materials, lighting and physics are unchanged.
- Footer text floats in white over the sphere scene without a white strip.
- Restored missing dependencies for the existing pinned Three.js and stats-gl renderer.
- Added Search with type filters, detail dialogs and connected-market entry points.
- Added persistent Watchlist and expanded Bookmarks to all registered demo markets.
- Completed Portfolio tabs for predictions, recent points activity and local market submissions.
- Wired discovery chips, category/entity cards and graph links into search.
- Removed unsupported calendar, AI, account and sidebar placeholder actions.
- Added meaningful featured-event filters, mobile navigation and responsive layouts.
- Added reduced-motion-aware GSAP scroll reveals and keyboard-accessible dialogs.
- Added in-app Learn and Changelog pages, demo-data labeling and finite-value guards.
- Documented backend gaps, centralized resolution and future oracle options in BACKEND_PLAN.md.
- Added browser regression tests for core flows, responsive routes and landing themes.
